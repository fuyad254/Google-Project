# 🔍 Google Homepage Clone

A simple **Google Homepage Clone** built using **HTML and CSS**.

This project holds a special place in my learning journey because it was the **first project of my life** after completing the basics of HTML and CSS by learning from free YouTube tutorials. I built this project to practice what I had learned and understand how a real-world website layout can be recreated using basic frontend technologies.

> 🚀 **This was my first step into frontend web development.**

## 🌐 Live Demo

🔗 Live Demo: https://fuyad254.github.io/Google-Project/

---

## 📌 Project Overview

This project is a beginner-level recreation of the Google Search homepage interface.

The main goal was not to build a fully functional search engine, but to practice:

* HTML page structure
* CSS positioning
* Flexbox
* Navigation layout
* Search box design
* Buttons and links
* Footer layout
* Basic responsive structure
* Using images and icons in a webpage

Building this project helped me understand how different HTML elements work together to create a complete webpage.
